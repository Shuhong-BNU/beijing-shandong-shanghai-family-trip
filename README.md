## 项目定位

这是一次真实家庭旅行的路线规划与执行工具。四段航班已经锁定，因此项目围绕固定航班倒推北京、青岛、威海、上海四地安排，并在山东段保留自驾 / 不自驾、深度 / 轻松等多条可切换路径。

核心目标：**父母体验优先、减少折返与过度疲劳、保留动态调整空间，并严格区分官方事实、规划判断、预估参考与真实支付账单。**

## 三套独立界面

- **方案速览**：比较 A–E 五套正式方案，选定当前执行方案；新增四城识别图帮助快速建立城市印象。
- **执行行程**：只显示当前选中的一个方案；“方案总流程”改为可折叠的 8 天摘要，不再堆叠 40+ 节点；“8 天执行流程”负责真正的逐节点执行。
- **完整研究**：天气、人流、景点池、住宿、逐餐、交通、租车、票务、成本、景点删减、方法与来源等研究层内容。

底部提供 **总览 / 每天 / 预订 / 研究** 四个快捷入口。

## 五套正式方案

- **A｜主推**：北京 1 / 青岛 2 / 威海 2 / 上海 2；青岛不租车，8 月 24 日威海单日自驾。
- **B｜零驾驶**：山东段以铁路 / 地铁 / 网约车为主。
- **C｜青岛深度**：青岛 3 晚 + 威海 1 晚，重点加入崂山。
- **D｜山东跨城自驾**：青岛取车，经荣成 / 威海活动，威海机场还车。
- **E｜慢节奏减负**：每天一个主项目 + 一个轻量散步或休息模块。

## v1.2.2 主要更新

### 执行流程

- **方案总流程可折叠**，并简化为 8 天摘要卡片，只显示日期、城市 / 转场、起终点和节点数量。
- **8 天执行流程继续保留详细节点**，且每一个节点都新增：
  - 日期
  - 所在城市
  - 节点名称
  - 时间
  - 动作 / 说明
- 跨城日重点表达交通接驳与关键时间；市内 / 近郊日重点表达节点顺序与节奏。
- 路线展示不是实时导航，出行当天仍以高德 / 百度、12306、航司和景区实时信息为准。

### 视觉增强

- 方案速览新增 **北京 / 青岛 / 威海 / 上海四城识别图**。
- 景点池新增轻量 **缩略图 / 图标列**，在不引入重型图片资源和外部图片依赖的前提下缓解大篇幅文字的阅读压力。
- 继续优先保证中国大陆网络环境下的稳定访问。

### 景点池与决策

- 保留四城 50+ 景点池。
- 同时提供 **全部景点总表** 和 **北京 / 青岛 / 威海 / 上海城市分表**。
- 景点统一使用 **100 分评分**，并保留优先级、通用简评和“本次怎么判断”。
- 评分维度：代表性 25 + 首访价值 20 + 带父母友好度 20 + 本次路线适配 20 + 暑期体验 10 + 执行难度 / 成本友好度 5。

### 票务与成本

- 抢票清单覆盖天安门广场、天安门城楼、国家博物馆、故宫、天坛、颐和园、北海公园、景山公园、海军博物馆、崂山、刘公岛、豫园等，并区分官网 / App / 微信小程序 / 开售或预约规则。
- 五方案同时保留：
  - **不含大交通的预估价格参考**：只用于量级判断；
  - **精确成本计算器**：动态价格只认真实订单 / 支付页 / 菜单。

## 价格原则

- 官方固定价可以直接进入精确计算。
- 酒店、租车、网约车、餐饮、铁路等动态商品以真实支付页 / 订单 / 菜单为准。
- 预估价格只作为独立的量级参考，不与“精确总成本”混用。

## 来源原则

外部事实优先引用政府、景区、学校、铁路、平台等第一方来源；规划判断单独标识。找不到稳定第一方网页的内容，会明确写明“次级来源 / 以官方小程序或最终订单为准”。
