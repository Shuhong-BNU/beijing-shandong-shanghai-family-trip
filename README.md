## 项目定位

这是一次真实家庭旅行的路线规划与执行工具。四段航班已经锁定，项目围绕固定航班倒推北京、青岛、威海、上海四地安排，并在山东段保留自驾 / 不自驾、深度 / 轻松等多条可切换路径。

规划目标：**父母体验优先、减少折返与过度疲劳、保留动态调整空间，并严格区分官方事实、规划判断、精确账单与预估参考。**

## 三套独立界面

- **方案速览**：比较 A–E 五套方案并选择当前方案，同时用四城真实代表图建立城市识别。
- **执行行程**：只显示当前方案；方案总流程可折叠，8 天执行流程显示逐节点日期、城市、距离、时长与内嵌地图。
- **完整研究**：保留天气、景点池、住宿、逐餐、交通、租车、票务、成本、删减、方法与来源。

底部提供 **总览 / 每天 / 预订 / 研究** 四个快捷入口。

## 五套正式方案

- **A｜主推**：北京 1 / 青岛 2 / 威海 2 / 上海 2；青岛不租车，8 月 24 日威海单日自驾。
- **B｜零驾驶**：山东段以铁路 / 地铁 / 网约车为主。
- **C｜青岛深度**：青岛 3 晚 + 威海 1 晚，重点加入崂山。
- **D｜山东跨城自驾**：青岛取车，经荣成 / 威海活动，威海机场还车。
- **E｜慢节奏减负**：每天一个主项目 + 一个轻量散步或休息模块。

## v1.3.0 主要更新

### 1. 转场距离与时间

每一段地点切换都增加距离 / 时间状态：

- **飞机**：使用机场间大圆直线距离；已锁定航班使用计划飞行时间。
- **驾车 / 网约车**：配置高德后使用实际道路规划距离和预计时长。
- **步行**：使用高德步行实际规划距离 / 时间。
- **地铁 / 公交 / 机场线**：使用高德公交规划；上海虹桥—浦东机场线同时保留官方约 40 分钟口径。
- **铁路**：可选高德 Web Service 查询跨城铁路距离 / 时间，最终仍以 12306 具体车次为准。
- **轮船**：刘公岛水上段显示约 5.6 km 直线水距；时间明确标为本行程执行预留，不冒充官方纯航行时长。

### 2. 每方案每天内嵌高德路线图

- A–E 五方案的每天都保留独立路线视图。
- 地图直接嵌在页面内，不要求跳到高德 App。
- 地图只显示编号 Marker 与真实规划路线，不把长标签叠在图上。
- 遇到飞机 / 铁路跨城日，自动拆成“出发地本地路线 → 长途转场卡 → 到达地本地路线”，避免全国尺度压扁市内节点。
- 未配置高德凭据时，执行流程与节点表仍完整可用。

### 3. 高德 Key 安全与调用控制

v1.3.0 **不把任何高德 Key 写入公开 GitHub 仓库**。页面提供本机配置：

- JS API Key
- `securityJsCode`
- 可选 Web Service Key
- 本站“每日未缓存算路上限”

配置只保存在当前浏览器 localStorage；路线结果缓存 30 天。建议在高德控制台把 `shuhong-bnu.github.io` 配入域名白名单。

> 页面里的每日上限只是本站客户端保护，不是高德官方账单硬上限；不要把“Key 泄漏也一定不会扣费”当成安全假设。

### 4. 真实图片

- 方案速览：北京 / 青岛 / 威海 / 上海各有真实代表图。
- 景点池：每个景点增加真实缩略图列。
- 美食表：每顿代表性食物增加真实缩略图。
- 图片通过 Wikimedia Commons 按需懒加载，并显示许可 / 来源链接；加载失败时回退图标，不使用 AI 图冒充真实照片。

### 5. 延续 v1.2.x 的改进

- 方案总流程保持可折叠，并只保留 8 天摘要。
- 8 天执行流程每个节点显示日期 + 所在城市。
- 景点池保留 100 分评分、全部景点总表、四城分表和优先级排序。
- 抢票清单、预估成本 / 精确成本分层、localStorage 成本台账继续保留。

## 地图与数据口径

高德地图属于**执行增强层**，不是唯一信息源。页面仍保留不依赖地图 API 的流程与表格作为兜底。

- 当天实际导航：以高德 / 百度实时路况为准。
- 铁路：以铁路 12306 具体车次为准。
- 航班：以已购订单与航司实时状态为准。
- 景区船班：以景区当日运营通知为准。

## 景点评分原则

100 分模型属于项目规划层判断：

- 代表性 / 城市地位：25
- 首次到访价值：20
- 带父母友好度：20
- 本次路线适配度：20
- 暑期体验质量：10
- 执行难度 / 成本友好度：5

评分用于横向决策，不冒充官方评级。

## 价格原则

- 官方固定价可以进入精确计算。
- 酒店、租车、网约车、餐饮、铁路等动态商品以真实支付页 / 订单 / 菜单为准。
- 预估价格只作为独立量级参考，不混入“精确总成本”。
- 精确成本输入保存在当前浏览器 localStorage。

## 来源原则

外部事实优先引用政府、景区、学校、铁路、平台等第一方来源。地图 API 技术口径来自高德开放平台；真实照片来自 Wikimedia Commons，并在页面标识来源 / 许可。
