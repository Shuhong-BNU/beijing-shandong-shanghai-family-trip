## 价格原则

固定官方价才写数字；酒店、租车、网约车、餐饮、尚未开售铁路和已购机票金额，在没有最终支付页 / 菜单 / 账单前不写估算金额。页面提供本地精确成本计算器。

## 地图说明

地图基于 OpenStreetMap，节点为规划级近似坐标，线段用于表达空间关系、移动方向与交通方式，不替代高德/百度等当天实时导航。

## 来源原则

外部事实尽量就地链接到政府、景区、学校、铁路、租车平台等第一方来源；规划判断单独标识，不伪装成官方结论。找不到稳定第一方网页的内容会明确标注次级来源和复核要求。
