## 项目定位

这是一次真实家庭旅行的路线规划与执行工具。四段航班已经锁定，因此项目围绕固定航班倒推北京、青岛、威海、上海四地安排，并在山东段保留自驾 / 不自驾、深度 / 轻松等多条可切换路径。

规划目标：**父母体验优先、减少折返与过度疲劳、保留动态调整空间，并严格区分官方事实、规划判断、精确账单与预估参考。**

## v1.2.0 的界面结构

页面从单一长文档重构为三套独立界面：

- **方案速览**：比较 A–E 五套方案并选定当前执行方案。
- **执行行程**：只显示当前选中的一个方案，包括方案总览、8 天逐日路线与预订重点。
- **完整研究**：保留天气、景点池、住宿、逐餐、交通、租车、票务、成本、删减、方法与来源等研究层内容。

底部提供 **总览 / 每天 / 预订 / 研究** 四个快捷入口。

## 五套正式方案

- **A｜主推**：北京 1 / 青岛 2 / 威海 2 / 上海 2；青岛不租车，8 月 24 日威海单日自驾。
- **B｜零驾驶**：山东段以铁路 / 地铁 / 网约车为主。
- **C｜青岛深度**：青岛 3 晚 + 威海 1 晚，重点加入崂山。
- **D｜山东跨城自驾**：青岛取车，经荣成 / 威海活动，威海机场还车。
- **E｜慢节奏减负**：每天一个主项目 + 一个轻量散步或休息模块。

## 地图原则

v1.2.0 默认地图不调用第三方底图服务，而是利用已有经纬度数据在浏览器中绘制 SVG 路线示意图。它用于表达节点顺序、空间关系、移动方向和交通方式，**不替代高德 / 百度等当天实时导航**。

未来若接入高德地图 Web JS API，可在保留本版静态 SVG 兜底的同时提供交互底图；是否接入取决于 API Key、安全配置与维护成本。

## 价格原则

- 官方固定价可以直接进入精确计算。
- 酒店、租车、网约车、餐饮、铁路等动态商品以真实支付页 / 订单 / 菜单为准。
- 预估价格只作为**独立的量级参考**，不得混入“精确总成本”。

## 来源原则

外部事实优先引用政府、景区、学校、铁路、平台等第一方来源；规划判断单独标识。找不到稳定第一方网页的内容，会明确写明“次级来源 / 以官方小程序或最终订单为准”。
