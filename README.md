## 项目定位

这是一次真实家庭旅行的路线规划、信息研究与执行手册。四段航班已锁定，因此核心不是从零设计线路，而是围绕固定航班倒推北京、青岛、威海、上海四地安排，并在山东段保留自驾 / 不自驾等可替换方案。

规划目标：**父母体验优先、减少折返与过度疲劳、保留动态调整空间，同时严格区分事实、规划判断和尚未发生的动态价格。**

## 五套正式方案

- **A｜主方案**：北京 1 / 青岛 2 / 威海 2 / 上海 2；青岛不租车，8 月 24 日威海单日租车。
- **B｜全程不自驾**：与主方案同样的城市夜数，铁路 / 地铁 / 网约车为主。
- **C｜青岛深度 + 崂山**：北京 1 / 青岛 3 / 威海 1 / 上海 2。
- **D｜山东跨城自驾**：青岛取车，经威海 / 荣成活动，威海机场还车。
- **E｜轻松低强度**：每天一个主景点 + 一个轻量散步或休息，主动删减高强度项目。

## 价格原则

**不为了得到“总预算”而编造数字。**

固定官方价才直接写入金额；酒店、租车、网约车、餐饮、尚未开售铁路以及已购机票等动态支出，在没有最终支付页、菜单或账单前不写估算金额。页面中的成本计算器只汇总已经确认的真实金额，并明确显示仍缺多少项。

## 地图说明

地图基于 OpenStreetMap。节点坐标属于**规划级近似坐标**，路线用于表达空间关系、移动方向与交通方式，不替代高德 / 百度等当天实时导航。

## 来源原则

外部事实尽量就地链接到政府、景区、学校、铁路、租车平台等第一方来源；规划判断与偏好单独标识，不伪装成官方结论。找不到稳定第一方网页的内容，会明确标注次级来源或待复核要求。
